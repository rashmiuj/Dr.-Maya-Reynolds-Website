# Dr. Maya Reynolds, PsyD — Clinical Psychology Practice Website

A modern, responsive, and grounded website built for **Dr. Maya Reynolds, PsyD**, a licensed clinical psychologist based in Santa Monica, California.

Cloned and creatively redesigned with Next.js (App Router) + Tailwind CSS, preserving the original layout structure while infusing a coastal Santa Monica clinical identity, authentic practice imagery, and a confidential intake flow.

---

## 🌟 Features & Design Highlights

- **Client-Centered Narrative Flow**:
  - **Hero Section**: Introduces Dr. Reynolds' practice in Santa Monica with a calm, welcoming headline and a direct booking call-to-action.
  - **About Dr. Maya Reynolds**: Features her official portrait, clinical background, and warm, collaborative therapy philosophy.
  - **3 Core Specializations**: Dedicated sections for Anxiety & Panic, Trauma & EMDR, and Burnout for High Achievers.
  - **Custom "Our Office" Section**: Showcases her physical Santa Monica office space with photos, physical address (`123th Street 45 W`), and in-person/telehealth availability.
  - **Evidence-Based Approach & FAQs**: Highlights modalities (CBT, EMDR, Somatic, Mindfulness) and interactive answers to common questions.
- **Interactive Intake Modal**:
  - Clean on-page button triggering a confidential intake modal inspired by modern counseling practices (Conejo Valley Counseling flow).
  - Includes First & Last Name, Email, Phone, Telehealth vs. In-Person dropdown with placeholder selection, Presenting Issues, and Minor Age fields.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile with fluid layouts and accessible touch targets.

---

## 🛠️ Tech Stack

- **Framework**: **Next.js (App Router)** + React 19 / TypeScript
- **Styling**: **Tailwind CSS**
- **Icons**: Lucide React
- **Animations / Interactions**: Smooth scroll, interactive FAQ accordions, image lightbox preview, and intake modal

## 🚀 Getting Started (Next.js)

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation & Run

1. Clone this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/dr-maya-reynolds-therapy.git
   cd dr-maya-reynolds-therapy
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```

## 🌐 Deployment to Vercel (1-Click)

This Next.js application is 100% Vercel-ready:

1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Select your repository. Vercel will automatically detect **Next.js**.
4. Click **Deploy**.
